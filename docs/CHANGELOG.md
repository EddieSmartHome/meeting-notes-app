# 版本更新紀錄

## v2.4.2（2026-10-23）
- 修正舊會議改不了名稱、地點、與會者：v2.4.0 之前建立的會議，只要另一台也動過這場會議，同步時剛改的內容會被另一台的舊內容蓋回去；現在以實際改過的欄位為準
- 同步在輸入途中完成時，不再打斷正在輸入的會議資訊欄位

## v2.4.1（2026-10-20）
- 修正分類沒有同步：v2.4.0 之前就建立的分類，兩台都沒改過時不會互傳；現在改為逐個分類合併，兩台的分類都會保留
- 兩台各自建了同名分類（例如都有「業務」）會自動合併成一個，裡面的會議一起移過去
- 設定也會同步：API 金鑰、常用專有名詞、辨識服務與模型、會議記錄設定、錄音設定；同一項設定兩台都改時以較晚改的為準
- 本機語音辨識模型（要各自下載）與「上傳錄音的網路環境」仍是每台各自設定

## v2.4.0（2026-10-20）
- 新增「雲端硬碟同步」（設定 →「雲端硬碟同步」）：多台裝置連結同一個 Google 帳號後，會議資訊、逐字稿、會議記錄、分類與錄音會自動同步
- 資料存在 Google 雲端硬碟裡本 App 專用的隱藏資料夾，不會出現在雲端硬碟畫面中；API 金鑰與裝置設定不會同步
- 錄音檔可分別勾選「連上 Wi-Fi 時」「使用行動網路時」才同步；文字資料隨時同步
- 兩台都改了同一場會議時，逐欄位以較新的修改為準（例如一台改名稱、另一台改與會者，兩邊都會保留）；刪除會議也會同步刪除
- 開啟 App、回到 App、修改後約 20 秒會自動同步，也可按「立即同步」
- 最低支援版本改為 Android 7.0（Google 登入元件的要求）
- 連結 Google 帳號失敗時，顯示 Google 回傳的完整錯誤（代碼名稱與說明），方便判斷設定問題（同版補充）

## v2.3.0（2026-10-20）
- 左側會議清單可用拖曳改分類：長按一場會議約半秒，清單上方會出現各分類（含「未分類」），拖到要放的分類上放開即可；電腦上按住滑鼠半秒後拖曳也可以
- 設定頁選「Groq Whisper」時，新增 Groq 註冊與 API 金鑰申請步驟，可直接點連結開啟（建議用 Email 註冊，避開 Google 登入時的 signup_blocked）

## v2.2.2（2026-10-20）
- 改善錄音音質：新增「收音模式」，預設改為「會議模式」，關閉通話用的降噪與回音消除，聲音較自然、遠處的人也收得到，不再忽大忽小；也可選「原音模式」或原本的「通話模式」（設定 →「錄音」）
- 錄音位元率預設從 32 kbps 提高到 64 kbps（一小時約 29 MB），可選 32／64／96 kbps
- 手機支援時，錄音改存成 m4a（較通用，多數播放器都能開），不支援才用 WebM；也可在設定固定用 WebM
- 播放器下方與設定頁會顯示錄音的格式、位元率與收音模式，方便比較
- 新設定從下一次錄音開始生效，之前的錄音不受影響

## v2.2.1（2026-10-20）
- 錄音播放器下方新增「存到手機」（存到「文件／會議速記／錄音」）與「分享錄音」；播放器內建的「下載」在 App 裡不會動作，已移除
- 重新轉錄改為只用選定的辨識方式：雲端被擋（例如額度用完）時會等待後重試，不再改用本機或其他模型，結果才能拿來比較
- 重新轉錄送到雲端時放慢速度（每段間隔約 6.5 秒），避開免費方案的每分鐘次數上限；被擋時畫面會顯示原因
- 逐字稿每段旁標示是由哪種方式轉出來的（Gemini／Transcribe／本機／Groq）；之前轉的段落沒有紀錄，不會顯示

## v2.2.0（2026-10-20）
- 會議畫面的逐字稿上方新增「辨識方式」選單，可直接切換 Gemini、Gemini Transcribe 或本機（離線）辨識，之後的轉錄都改用它（和設定頁同步）
- 新增「用這個方式重新轉錄」：用目前選的辨識方式，把整場會議的原始錄音重新切段、轉錄一次；按兩次才會執行，會取代目前的逐字稿
- 重新轉錄前的逐字稿會保留，可按「復原上一版」切回（再按一次可切換回新的版本）

## v2.1.1（2026-10-20）
- 修正本機辨識會掉字（例如「工廠」變成「工」）：原因是辨識引擎 sherpa-onnx 1.13.8 的已知問題，改用含官方修正的版本
- 本機辨識的模型改從本 App 的 GitHub 下載，不再經由 Hugging Face；v2.1.0 已下載的模型會沿用，不會重新下載
- 本機辨識偶爾會不斷重複同一句話，現在會自動刪掉多餘的重複
- 修正 Gemini Transcribe 常掉句：它回傳空白時，之前會當成沒人說話直接丟掉；現在改用 Gemini 主模型重轉這段，並跳出提示。錄音片段也改轉成 WAV 再送出（同版補充）
- 設定頁（轉錄服務選 Gemini Transcribe 時）可查看最近一次沒有回傳文字的紀錄，方便判斷原因（同版補充）

## v2.1.0（2026-10-20）
- 新增「本機辨識（離線）」：在手機上用 Whisper Small 模型辨識語音，不需網路、不受免費額度限制（設定 →「本機辨識（離線）」）
- 模型不放在 App 裡，第一次使用時在設定按「下載模型」（約 375 MB，建議用 Wi-Fi），之後可隨時刪除
- 兩種使用方式：「雲端連不上、忙碌或額度用完時改用本機」，或「一律使用本機」（錄音不會上傳，適合機密會議）
- 沒有填雲端金鑰、但已下載模型時，也會直接用本機辨識
- 本機辨識速度依手機效能而定，通常比雲端慢，準確度一般也比 Gemini 低

## v2.0.8（2026-10-20）
- 轉錄服務新增「Gemini Transcribe」：Google 的語音轉錄專用模型（gemini-3.5-transcribe，預覽版），免費方案可用，共用 Gemini 金鑰；在 設定 →「語音轉文字」→「轉錄服務」切換
- 使用 Gemini Transcribe 時，「常用專有名詞」會一併送出提高辨識率（最多 100 個）
- Gemini Transcribe 忙碌時，該段自動改用設定的備用模型轉錄
- 使用 Gemini Transcribe 時，每段錄音內各句的時間點依字數平均估算，點逐字稿跳轉的位置可能差幾秒

## v2.0.7（2026-10-20）
- 設定的 Gemini 模型改為下拉選單，分成「主模型」與「備用模型（主模型忙碌時改用）」兩個，備用模型也可選「不使用」
- 選單內容直接取自 Google 目前提供的 Gemini 模型清單：填入金鑰、開啟設定（超過 1 小時）或開啟 App（超過 1 天）時自動更新，也可按「更新模型清單」
- 選用的模型被 Google 下架時，會自動改用最新的正式版 Flash（主模型）或 Flash-Lite（備用模型），並跳出提示
- 選單只列免費方案可用的模型（Flash 與 Flash-Lite 系列），不列 Pro 等需付費的模型；之前選了付費模型會自動換成免費模型（同版補充）

## v2.0.6（2026-10-20）
- 轉錄加快：Gemini 轉錄時的「思考程度」預設改為「低」，可在設定改回「中」（模型預設）
- Gemini 主模型忙碌（HTTP 5xx）時，該段自動改用備用模型 gemini-3.5-flash-lite 轉錄，不必等主模型恢復
- 修正轉錄有時一直停在「轉錄中」不動：每段轉錄最多等 3 分鐘，逾時就自動重送；另外每 30 秒檢查一次，佇列沒在跑就重新啟動
- 轉錄中會顯示這一段已經等了幾秒

## v2.0.5（2026-10-20）
- 轉錄遇到網路不穩（斷線、Wi-Fi 與行動網路切換、螢幕關閉時）不再約 10 秒就放棄：會持續自動重試，間隔逐步拉長到最多 1 分鐘，網路恢復後自動補完
- Gemini／Groq 免費額度暫時用完或服務忙碌時，也改為等待後持續重試，不算失敗
- 每次轉錄請求最多等 2 分鐘，避免卡住整個佇列；產生會議記錄最多等 5 分鐘
- 回到 App 畫面時，會立刻補送還沒轉錄的片段；等待中也可以按「重試」立刻再送
- 錯誤訊息會附上實際原因（例如逾時或連線中斷），方便判斷問題

## v2.0.4（2026-10-20）

- Android 13 以上第一次錄音時會詢問是否允許通知；不允許也能錄音，只是通知列看不到「錄音中」
- 設定新增「錄音」區塊：可選擇錄音時是否保持螢幕開啟（預設開啟）

## v2.0.0（2026-10-20）
首次公開版本。版號從 v2.0.0 重新開始，之前的 v1.0.x 是開發期間的版本，Release 已移除（紀錄保留在 docs/CHANGELOG.md）。

與 v1.0.9 相比的變更：
- 每次開啟 App 都自動檢查新版本；有新版就自動下載並跳出安裝畫面，按「更新」即可（錄音中會等錄音結束才更新）
- repo 公開後，檢查更新不需要 GitHub 存取權杖；只有私人 repo 才需要
- 設定頁的「App 更新」說明改寫，說明權杖只有私人 repo 才需要
- **更換簽章金鑰**：舊金鑰曾存放在公開的 repo 中，已改用新金鑰，並只存在 GitHub Secrets。因為簽章不同，**已安裝的舊版（v1.x 與更早的 v2.0.0）無法直接覆蓋**：請先在 App 用「備份與還原」備份，移除舊 App，安裝這一版後再還原。之後的版本都可以直接自動更新

目前功能一覽：
- 中英文會議錄音，分段轉成逐字稿（中英夾雜自動辨識），保存原始錄音
- 點逐字稿跳到該段錄音播放；播放時標亮目前段落
- 會議清單、搜尋、自訂分類與分類篩選
- 由 Gemini（免費）或 Claude 整理會議記錄；每個分類可設定自己的格式
- 備份與還原：存到手機或分享到 Google 雲端硬碟
- 開啟 App 自動檢查並更新

# 公開前的開發版本（v1.0.2–v1.0.9，Release 已移除）

### v1.0.9（2026-10-20）
- 新增「會議分類」
  - 在 ☰ → 設定 →「會議分類」新增、改名、刪除分類（刪除後，該分類的會議變成未分類）
  - 會議資訊可以選擇分類；新會議會自動帶入左側清單目前篩選的分類
  - 左側清單可依分類篩選（全部分類／各分類／未分類），每場會議顯示分類標籤；搜尋也會比對分類名稱
- 新增「分類專屬的會議記錄格式」
  - 每個分類可以設定自己的會議記錄格式，產生會議記錄時改用該格式；沒設定就用預設格式
  - 「填入預設格式再修改」可以從預設格式開始調整
  - 會議記錄的提示詞會帶入分類名稱
- 新增「檢查更新」
  - 側邊選單最下方與設定頁都有「檢查更新」按鈕，查詢 GitHub 上的最新版本並顯示更新內容
  - 有新版時按「下載並安裝」，App 會自動下載 APK 並開啟安裝程式
  - 需要在設定填入只能讀取這個 repo 的 GitHub 存取權杖（設定頁附申請步驟）
  - 填好權杖後，App 開啟時每 12 小時最多自動檢查一次，有新版會在側邊選單顯示「有新版本」
  - 新增「安裝應用程式」權限，用於開啟下載的更新檔
- 備份
  - 備份檔加入分類；還原時，備份裡有、手機上沒有的分類會自動補上
  - GitHub 存取權杖和其他金鑰一樣，只有勾選「包含 API 金鑰」才會放進備份檔

### v1.0.8（2026-10-20）
- 新增「備份與還原」（左上 ☰ → 備份與還原）
  - 備份內容：設定，以及每場會議的錄音、逐字稿（.txt，含時間點與 ★ 重點）、會議記錄（.md）、尚未轉錄完的錄音片段，打包成一個 .zip
  - 範圍可選「全部會議」或「目前開啟的會議」；可選擇不含錄音，讓檔案變小
  - API 金鑰預設不放進備份檔，需要時才勾選
  - 「存到手機」：存到手機的「文件／會議速記」資料夾，移除 App 也不會刪除
  - 「分享／存到雲端硬碟」：開啟分享選單，選「雲端硬碟」即可存到 Google 雲端硬碟
  - 還原：選擇備份的 .zip；手機上已有的同一場會議可選「略過」或「覆蓋」；可一併還原設定（備份檔不含金鑰時，保留手機上原本的金鑰）
  - 顯示上次備份時間
- 側邊選單最下方顯示 App 版本
- 新增儲存權限（只有 Android 10 以下的手機會用到，用於存到「文件」資料夾）
