# 版本更新紀錄

## v2.0.1（2026-10-20）
- 移除「GitHub 存取權杖」與「GitHub repo」設定：repo 已公開，檢查更新與自動更新不需要任何設定
- 設定頁的「App 更新」簡化為一句說明和「檢查更新」按鈕
- 更新檔改從 Release 的公開下載網址下載
- 舊版儲存的權杖設定會在開啟 App 時自動清除；備份與還原也不再處理權杖
- 修正「下載並安裝」失敗（Error downloading file … ENOENT）：更新檔改存在快取最外層。此問題出在更新功能本身，已安裝的 v2.0.1 需手動下載安裝一次修正後的版本

## v2.0.0（2026-10-20）
首次公開版本。版號從 v2.0.0 重新開始，之前的 v1.0.x 是開發期間的版本，Release 已移除（紀錄保留在 docs/CHANGELOG.md）。

與 v1.0.9 相比的變更：
- 每次開啟 App 都自動檢查新版本；有新版就自動下載並跳出安裝畫面，按「更新」即可（錄音中會等錄音結束才更新）
- repo 公開後，檢查更新不需要 GitHub 存取權杖；只有私人 repo 才需要
- 設定頁的「App 更新」說明改寫，說明權杖只有私人 repo 才需要
- **更換簽章金鑰**：舊金鑰曾存放在公開的 repo 中，已改用新金鑰，並只存在 GitHub Secrets。因為簽章不同，**已安裝的舊版（v1.x 與更早的 v2.0.0）無法直接覆蓋**：請先在 App 用「備份與還原」備份，移除舊 App，安裝這一版後再還原。之後的版本都可以直接自動更新

目前功能一覽：
- 中英文會議錄音，分段轉成逐字稿（中英夾雜自動辨識），保存原始錄音
- 點逐字稿跳到該段錄音播放；播放時標亮目前段落
- 會議清單、搜尋、自訂分類與分類篩選
- 由 Gemini（免費）或 Claude 整理會議記錄；每個分類可設定自己的格式
- 備份與還原：存到手機或分享到 Google 雲端硬碟
- 開啟 App 自動檢查並更新

# 公開前的開發版本（v1.0.2–v1.0.9，Release 已移除）

### v1.0.9（2026-10-20）
- 新增「會議分類」
  - 在 ☰ → 設定 →「會議分類」新增、改名、刪除分類（刪除後，該分類的會議變成未分類）
  - 會議資訊可以選擇分類；新會議會自動帶入左側清單目前篩選的分類
  - 左側清單可依分類篩選（全部分類／各分類／未分類），每場會議顯示分類標籤；搜尋也會比對分類名稱
- 新增「分類專屬的會議記錄格式」
  - 每個分類可以設定自己的會議記錄格式，產生會議記錄時改用該格式；沒設定就用預設格式
  - 「填入預設格式再修改」可以從預設格式開始調整
  - 會議記錄的提示詞會帶入分類名稱
- 新增「檢查更新」
  - 側邊選單最下方與設定頁都有「檢查更新」按鈕，查詢 GitHub 上的最新版本並顯示更新內容
  - 有新版時按「下載並安裝」，App 會自動下載 APK 並開啟安裝程式
  - 需要在設定填入只能讀取這個 repo 的 GitHub 存取權杖（設定頁附申請步驟）
  - 填好權杖後，App 開啟時每 12 小時最多自動檢查一次，有新版會在側邊選單顯示「有新版本」
  - 新增「安裝應用程式」權限，用於開啟下載的更新檔
- 備份
  - 備份檔加入分類；還原時，備份裡有、手機上沒有的分類會自動補上
  - GitHub 存取權杖和其他金鑰一樣，只有勾選「包含 API 金鑰」才會放進備份檔

### v1.0.8（2026-10-20）
- 新增「備份與還原」（左上 ☰ → 備份與還原）
  - 備份內容：設定，以及每場會議的錄音、逐字稿（.txt，含時間點與 ★ 重點）、會議記錄（.md）、尚未轉錄完的錄音片段，打包成一個 .zip
  - 範圍可選「全部會議」或「目前開啟的會議」；可選擇不含錄音，讓檔案變小
  - API 金鑰預設不放進備份檔，需要時才勾選
  - 「存到手機」：存到手機的「文件／會議速記」資料夾，移除 App 也不會刪除
  - 「分享／存到雲端硬碟」：開啟分享選單，選「雲端硬碟」即可存到 Google 雲端硬碟
  - 還原：選擇備份的 .zip；手機上已有的同一場會議可選「略過」或「覆蓋」；可一併還原設定（備份檔不含金鑰時，保留手機上原本的金鑰）
  - 顯示上次備份時間
- 側邊選單最下方顯示 App 版本
- 新增儲存權限（只有 Android 10 以下的手機會用到，用於存到「文件」資料夾）
