錄音

「會議模式」關閉降噪與回音消除，保留自動音量，聲音較自然、遠處的人也收得到；「通話模式」適合對著手機講話，但會讓聲音變悶、忽大忽小。改了之後從下一次錄音開始生效。

錄音時通知列會顯示「錄音中」，螢幕關閉或切到其他 App 也會持續收音。Android 13 以上第一次錄音時會詢問是否允許通知；不允許也能錄音，只是通知列看不到。

轉錄使用 Google 的語音轉錄專用模型 gemini-3.5-transcribe（預覽版）。它忙碌時，該段改用上方的備用模型轉錄；主模型用於產生會議記錄。每段錄音（約 10–25 秒）的時間點依字數平均估算，點逐字稿時位置可能差幾秒。

本機辨識（離線）

          

            

              

          

          

          

          

          
使用 OpenAI 的 Whisper Small 模型（int8 版本，從本 App 的 GitHub 下載），在手機上離線辨識。速度依手機效能而定，通常比雲端慢；準確度一般也比 Gemini 低，但不需網路、不受免費額度限制。建議用 Wi-Fi 下載。第一次辨識需要幾秒載入模型。

        

        

          
會議記錄

          

            

              

            

            

            

          

          
不想用 API 時，可按會議頁的「複製提示詞」貼到 Claude App 整理。金鑰、錄音與逐字稿都只存在這台手機上，移除 App 會一併刪除。

        

        

          
會議分類

          
自訂會議的分類（例如：週會、客戶會議、專案檢討）。每個分類可以設定自己的會議記錄格式；沒有設定就用預設格式。

          

          

          

            
            
            
            
          

          

        

        

          
App 更新

          
開啟 App 時會自動檢查新版本，有新版就自動下載並跳出安裝畫面，按「更新」即可。錄音中不會打擾，會等錄音結束。

          

        

        

      


      
      

        

          
備份

          
備份檔是一個 .zip 壓縮檔，內含設定，以及每場會議的錄音、逐字稿與會議記錄。電腦上解壓縮就能直接查看。

          

            

              

            

              

            
          

          

          

            
            
          

          

          
「存到手機」會存到手機的「文件（Documents）／會議速記」資料夾，移除 App 也不會刪除。「分享／存到雲端硬碟」會開啟分享選單，選「雲端硬碟」即可上傳到 Google 雲端硬碟。

        

        

          
還原

          
選擇之前備份的 .zip 檔，可以從手機的「文件」資料夾或 Google 雲端硬碟選取。
